Создай статический HTML-сайт на венгерском языке, стилизованный как контентный блог или обзорный сайт.

### Основные требования:

1. Главная страница (index.html)
   - Заголовок: „TOP 5 természetes szív- és érrendszeri termék”
   - Краткий обзор пяти натуральных продуктов для сердца и сосудов
   - Каждый продукт в виде карточки с изображением, кратким описанием, рейтингом (Schema.org), кнопкой "További információ"
   - Продукт №1 — „Tonerin” (с максимально положительным обзором)

2. Страницы-обзоры:
   - `/tonerin.html` — подробный обзор Tonerin
   - `/product2.html`, `/product3.html`, и т.д. — нейтральные обзоры других "продуктов"
   - В каждом обзоре:
     - Польза
     - Состав
     - Плюсы и минусы
     - 2–3 подставных отзыва
     - Кнопка «További információ» ведущая на внешний URL (редирект на оффер)

3. Навигация:
   - Верхнее меню: Főoldal, Termékek, Rólunk, Kapcsolat
   - Футер с ссылками: Adatvédelmi irányelvek, Felhasználási feltételek, Cookie-k kezelése

4. Дополнительные страницы:
   - `/adatvedelmi.html` — политика конфиденциальности (Adatvédelmi irányelvek)
   - `/rolunk.html` — страница «О нас»
   - `/kapcsolat.html` — контакты (можно фейковые)
   - `/sutik.html` — политика cookie

5. SEO:
   - Все страницы с мета-тегами: title, description
   - Использовать микроразметку Schema.org для рейтингов и отзывов
   - Скорость загрузки — высокая (не использовать тяжёлые библиотеки)

6. Дизайн:
   - Лёгкий и чистый стиль
   - Мобильная адаптация (responsive)
   - Использовать CSS-фреймворк (например, Bootstrap 5) или Tailwind CSS

7. Контент:
   - На венгерском языке
   - Без агрессивных мед. утверждений
   - Без слов: "gyógyít", "betegség", "orvosi kezelés"
   - Можно использовать фразы: "természetes támogatás", "jó közérzet", "kardiovaszkuláris egészség"

8. Безопасность:
   - Все внешние ссылки открываются в `target="_blank"` и с `rel="nofollow"`

9. Редиректы:
   - На странице Tonerin кнопка ведёт на внешний URL: `https://hu.tonerin-remedy.com/`

Результат должен быть в виде папки с HTML-файлами, CSS, изображениями (можно placeholder), готовой к заливке на хостинг.
